# Bounded Custom XML Tokenizer for Safe JUnit Parsing

Status: accepted (generated, pending human review)

## Context

External JUnit XML reports generated by diverse CI runners may contain adversarial payloads such as billion laughs entity expansions, XXE references, or deeply nested tag structures. We need a lightweight, zero-dependency parser that enforces strict bounds.

## Decision

Implement a pure TypeScript linear XML tokenizer with depth checks, input size limits, and outright rejection of DOCTYPE declarations. Predefined and numeric entities are supported without recursive expansion.

## Consequences

Protects memory and execution time against malformed or malicious inputs while accurately extracting standard JUnit and Maven Surefire testcase structures.
